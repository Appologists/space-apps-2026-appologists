        WHERE, AND WHEN, TO LAND ON THE MOON.

        At the south pole the Sun and Earth sit near the horizon, so a small change in place or date changes everything. We built a tool that compares sites and dates fast, for planners, teachers and the public.

        HOW WE WORK

        1. Every number comes from a named NASA dataset, or says “our estimate”.
        2. One coordinate rule everywhere: north and east positive, longitude −180° to 180°.
        3. No data is invented. A site with no data is left out, not given a zero.
        4. The Sun and Earth maths is checked against NASA/JPL Horizons, with tests that run on each change.
        5. Each change goes through a pull request before it reaches main.

        THE THREE PARTS

        • Finder (/): a 3D globe, a landing search on LOLA terrain, route choices and a drive plan for the rover.
        • Explorer (/classic): site ranking for any date, and a street view on real terrain with JPL Horizons positions.
        • Learn (/learn): this page. Plain HTML and JavaScript, no build step.
